RESTful API Toko Buku Online

Deskripsi Project

Project ini merupakan RESTful API yang dibangun menggunakan Node.js dan Express.js dengan studi kasus Toko Buku Online. API menyediakan fitur pengelolaan data buku dan data pembelian buku menggunakan konsep CRUD (Create, Read, Update, Delete).

Endpoint API

Dokumentasi

- GET /api/docs

Buku

- GET /api/v1/buku
- GET /api/v1/buku/:id
- POST /api/v1/buku
- PUT /api/v1/buku/:id
- DELETE /api/v1/buku/:id

Pembelian

- GET /api/v1/pembelian
- GET /api/v1/pembelian/:id
- POST /api/v1/pembelian
- PUT /api/v1/pembelian/:id
- DELETE /api/v1/pembelian/:id

Teknologi yang Digunakan

- Node.js
- Express.js
- Thunder Client
- Visual Studio Code

Tujuan

Membangun RESTful API yang mampu mengelola data buku dan transaksi pembelian serta menerapkan konsep HTTP Method GET, POST, PUT, dan DELETE sesuai standar REST API.
